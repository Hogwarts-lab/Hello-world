## Visual Studio 2022 Developer Command Prompt v17.14.22

### 什么是 Visual Studio 2022 Developer Command Prompt？(What is it?)

Visual Studio 2022 Developer Command Prompt（开发人员命令提示符）是 Microsoft Visual Studio 2022 集成开发环境附带的一个专用命令行工具。

**English:** Visual Studio 2022 Developer Command Prompt is a specialized command-line tool that comes with Microsoft Visual Studio 2022 IDE.

### 主要功能 (Key Features)

1. **预配置的环境变量 (Pre-configured Environment Variables)**
   - 自动设置编译器、链接器和其他构建工具的路径
   - Automatically sets up paths for compilers, linkers, and other build tools

2. **访问开发工具 (Access to Development Tools)**
   - MSBuild - 项目构建引擎 (Project build engine)
   - CL.exe - C/C++ 编译器 (C/C++ compiler)
   - Link.exe - 链接器 (Linker)
   - NMake - 构建自动化工具 (Build automation tool)
   - 以及其他 Visual Studio 开发工具 (and other VS development tools)

3. **版本信息 (Version Information)**
   - v17.14.22 表示这是 Visual Studio 2022 的版本 17.14.22
   - v17.14.22 indicates this is version 17.14.22 of Visual Studio 2022

### 使用场景 (Use Cases)

- 从命令行编译 C/C++ 项目 (Compile C/C++ projects from command line)
- 构建 .NET 应用程序 (Build .NET applications)
- 运行自动化构建脚本 (Run automated build scripts)
- 访问底层开发工具而无需完整的 IDE (Access low-level dev tools without full IDE)

### 如何启动 (How to Launch)

从开始菜单搜索 "Developer Command Prompt for VS 2022" 或在 Visual Studio 安装目录中找到相应的批处理文件。

Search for "Developer Command Prompt for VS 2022" in Start menu or locate the batch file in Visual Studio installation directory.
